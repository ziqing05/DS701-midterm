# DS701 Midterm — Bank Marketing

**Team:** Will Stiller, Sachiel Chuckrow, Ziqing Ye

## Objective

We analyze the Bank Marketing dataset to answer three questions:

1. Can we rank clients before dialing to identify more subscribers within a fixed contact budget?
2. Can we predict whether a client will subscribe?
3. Can we identify meaningful customer groups and use them to prioritize outreach?

Our project combines supervised prediction with unsupervised dimensionality reduction and clustering.
