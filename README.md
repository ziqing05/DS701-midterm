# DS701 Midterm — Bank Marketing

**Team:** Will Stiller, Sachiel Chuckrow, Ziqing Ye

This project analyzes the Bank Marketing dataset through client ranking, subscription prediction, and customer segmentation.

## Repository Guide

| File / Folder | Description |
|---|---|
| `QUESTIONS.md` | Research questions submitted for the earlier checkpoints. Also contains our validation plan. |
| `Merged_EDA.ipynb` | Exploratory data analysis submitted for the earlier checkpoint, covering dataset characteristics and initial findings. |
| `bank-additional-full.csv` | The Bank Marketing dataset used throughout the project. |
| `CONTRIBUTIONS.md` | Each team member’s responsibilities and contributions. |
| `Project_Question_Analysis.ipynb` | Our final runnable notebook containing the project analyses and results. |
| `report.md` | Source of our final report, organized around the research questions, approaches, evidence, and limitations. The submitted PDF is limited to three pages. |
| `SVD-Analysis/` | Supporting Q3 materials, including earlier experiments and historical results. The final notebook and report contain our final results. |

## Running the Analysis

Open `Project_Question_Analysis.ipynb` in Google Colab and run the cells in order. Follow the notebook’s data-loading instructions to provide `bank-additional-full.csv`.
